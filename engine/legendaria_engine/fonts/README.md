# Bundled fonts

Open-licence families for the subtitle look, so the preview in the browser and the burned video match on any computer without installing anything. `fonts.json` is the catalogue the editor reads (family, file, category). To add a font: put the `.ttf` here and add a line to `fonts.json`.

All are from [Google Fonts](https://fonts.google.com) under the [SIL Open Font License 1.1](https://openfontlicense.org) (which allows bundling and redistributing), each by its own authors: Montserrat, Lato, Raleway, Nunito, Comfortaa, Fredoka One, Oswald, Anton, Bebas Neue, Passion One, Archivo Black, Titan One, Righteous, Bangers, Orbitron, Press Start 2P, Playfair Display, Merriweather, Pacifico. The licence text and copyright of each family is in its upstream repository on Google Fonts.
