# Open Subtitler

Gerador automático de legendas para vídeos, de código aberto — inspirado nas legendas automáticas do CapCut.

> 🚧 Em desenvolvimento inicial.

## Objetivo

- Transcrever automaticamente o áudio de vídeos
- Gerar legendas sincronizadas (palavra a palavra)
- Estilizar e "queimar" as legendas no vídeo ou exportar em SRT/VTT/ASS
